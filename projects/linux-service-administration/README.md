# Linux Service Administration

## Overview

This project demonstrates how to create, deploy, manage, troubleshoot, and monitor a custom Linux service using `systemd`.

The service is implemented as a Bash script and managed using a custom `.service` unit file.

---

## Skills Demonstrated

- Bash scripting
- systemd service creation
- Service deployment
- Service lifecycle management
- journalctl log analysis
- Service troubleshooting
- Automatic restart policies
- Linux process management
- Documentation
- Testing
