# Linux Storage Administration

## Overview

This project demonstrates practical Linux storage administration using Rocky Linux.

A custom Bash script was developed to inspect storage devices, filesystems, mount points, UUIDs, capacity and directory usage, then generate a professional timestamped audit report.

---

## Skills Demonstrated

- Linux storage administration
- Block-device inspection
- Filesystem analysis
- LVM awareness
- Mount configuration
- Disk-usage analysis
- Bash scripting
- System auditing

---

## Features

- Physical disk detection
- Partition and logical-volume inspection
- Filesystem and UUID reporting
- Mounted-filesystem inspection
- Root and boot capacity monitoring
- Directory-usage analysis
- Largest-file reporting
- `/etc/fstab` review
- HEALTHY, WARNING and CRITICAL classifications
- Timestamped audit reports

---

## Technologies Used

- Rocky Linux 9
- Bash
- `lsblk`
- `blkid`
- `df`
- `du`
- `findmnt`
- `awk`
- `grep`

## Learning Outcomes

This project demonstrates how Linux storage can be inspected, interpreted and automatically documented using Bash.
