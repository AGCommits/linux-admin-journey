# Project Review

## Objectives

✔ Identify block devices.

✔ Interpret partitions and LVM logical volumes.

✔ Inspect filesystems and UUIDs.

✔ Analyse filesystem and directory usage.

✔ Review `/etc/fstab`.

✔ Generate a storage audit report.

✔ Add storage health classifications.

---

## Outcome

Project completed successfully.

A reusable Linux Storage Audit Tool was created that produces a timestamped report with both detailed storage information and a concise executive summary.

---

This project demonstrates practical storage administration skills expected of junior Linux administrators.

It complements previous projects covering:

- Bash scripting
- User management
- Log analysis
- Backup automation
- systemd services
- Networking
- Package management
