# Linux Storage Administration - Design

## Project Objective

Develop practical Linux storage administration skills using Rocky Linux.

The project focuses on inspecting, understanding, documenting and auditing Linux storage devices, filesystems and disk usage.

---

## Problem Being Solved

Linux administrators must understand how storage is organised to manage capacity, troubleshoot issues and maintain reliable systems.

The project develops practical skills for analysing storage configuration and filesystem usage.

---

## Key Concepts

- Block Devices
- Filesystems
- Mount Points
- UUIDs
- Disk Usage
- Directory Usage
- /etc/fstab
- Storage Auditing

---

## Tools Used

```bash
lsblk
blkid
df
du
findmnt
```

---

## Real World Administrator Tasks

- Identify attached storage devices.
- Verify mounted filesystems.
- Review filesystem UUIDs.
- Monitor disk usage.
- Locate directories consuming storage.
- Review mount configuration.
- Audit storage health.

---

## Project Phases

1. Storage discovery
2. Filesystem inspection
3. Disk usage analysis
4. Mount configuration
5. Storage auditing
6. Automation

## Success Criteria

The project is successful when I can:

- Identify storage devices.
